# Open-book Notes

这里存放最终可打印的双语 Markdown 开卷材料。每章只保留：

1. 题型识别信号；
2. 必要公式及适用条件；
3. 固定解题步骤；
4. 易混概念对比；
5. 已验证的典型错误；
6. 详细知识库或来源的快速定位。

只有“已理解、已测试、已纠正”的内容才能进入。Markdown 是主版本；PDF 与其并存。

## 修改权限

正式开卷资料默认不自动修改。Agent 负责判断是否存在值得修改的内容，但先写入 [`update_queue.md`](update_queue.md)：

- 新的官方资料补充或纠正了考试相关内容；
- 测试发现内容缺失、难以检索、条件不全或无法直接执行；
- 正式资料与更高优先级来源冲突；
- 某项内容已经通过理解、测试和复测，具备收录价值。

只有用户明确要求生成、修改，或确认具体待办后，Agent 才能改动正式资料。单纯上传文件、完成讲解或产生排版偏好，不构成自动修改授权。

修改后必须记录 Git 版本，并通过检索测试或近似迁移题验证；验证失败的待办不能关闭。
